Kebijakan Privasi YourTask

Terakhir diperbarui: 15 September 2026

1. Ringkasan

YourTask adalah aplikasi local-first: seluruh data Anda (profil, jadwal pelajaran, tugas, dan pengaturan) disimpan hanya di perangkat Anda, di dalam browser, terenkripsi dengan AES-256-GCM pada IndexedDB. Kami tidak memiliki server, tidak membuat akun, dan tidak mengumpulkan data pribadi apa pun.

2. Data yang disimpan di perangkat Anda

  • Nama dan asal sekolah (untuk tampilan sapaan)
  • Jadwal pelajaran dan daftar tugas
  • Pengaturan: zona waktu, hari aktif, offset sinkronisasi waktu
  • Kunci enkripsi AES-256 (non-extractable) — tidak dapat diekspor oleh JavaScript

Data ini tidak pernah dikirim ke kami karena kami tidak mengoperasikan server. Data hilang hanya jika Anda menghapus data situs di browser.

3. Layanan pihak ketiga yang dihubungi

  • Google Gemini API (generativelanguage.googleapis.com) — hanya saat Anda sengaja menggunakan fitur Pindai AI. Gambar/PDF jadwal yang Anda pilih dikirim langsung dari perangkat Anda ke Google untuk diproses menjadi teks jadwal. Google memprosesnya sesuai Kebijakan Privasi Google. App tidak mengirim data ini secara otomatis. Jika Anda memakai kunci API milik sendiri, kunci itu tersimpan terenkripsi di perangkat Anda dan tidak dikirim ke mana pun selain Google.
  • WorldTimeAPI (worldtimeapi.org) — untuk sinkronisasi jam (memastikan hitungan KBM dan alarm deadline akurat meski jam perangkat salah). Yang dikirim hanyalah permintaan waktu standar; tidak ada data Anda.
  • Google Fonts — dimuat untuk tampilan aplikasi.

4. Notifikasi

Notifikasi deadline bersifat lokal: dibuat langsung di perangkat oleh service worker dan hanya muncul setelah Anda memberi izin. Tidak ada push dari server eksternal.

5. Anak-anak

YourTask tidak sengaja ditujukan untuk anak di bawah 13 tahun dan tidak mengumpulkan data apa pun dari siapa pun, termasuk anak-anak. Jika Anda orang tua/wali dan memiliki pertanyaan, hubungi kontak di bawah.

6. Perubahan kebijakan

Jika kebijakan ini berubah (misalnya saat fitur sinkronisasi cloud ditambahkan), tanggal pembaruan di atas akan diubah dan perubahan akan diumumkan di dalam aplikasi.
