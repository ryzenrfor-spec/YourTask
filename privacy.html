Privacy Policy

Effective date: September 18, 2026 · Developer: ErlanggaDev Studios

YourTask ("the application") is developed and maintained by ErlanggaDev Studios (contact: erlanggadev.studios@gmail.com). This policy explains, in plain language, what data the application handles and how it is protected.

1. Summary

  • We do not collect your data. YourTask has no accounts, no analytics SDKs and no advertising.
  • Your data stays on your device. Schedules, tasks and settings are stored only in your browser's local storage, encrypted with AES-256-GCM.
  • No server receives your data. All core features work fully offline.

2. Data stored on your device

The application stores the following data locally:

  • Display name and school name (optional profile fields);
  • Class schedule and task list;
  • Interface preferences: language, time zone, theme, custom wallpaper and icon;
  • Backup file name preference.

3. Encryption

All data above is encrypted with AES-256-GCM (NIST SP 800-38D) using the Web Crypto API. The encryption key is generated on your device and marked non-extractable: the browser guarantees that no script — including ours — can read or export the raw key material.

4. Network access

The application makes exactly two optional network requests:

  • Time synchronization — a public time API (worldtimeapi.org) is queried when your device clock appears to drift. Only the current time is received; no personal data is sent.
  • AI document scan (opt-in) — if you provide your own Google Gemini API key and explicitly use "AI Scan", the selected schedule document is sent directly from your device to Google's Generative Language API. The request is not routed through our servers and we never see your key or your documents. Without a key, this feature is inert.

5. Notifications

Deadline reminders are generated on your device by the application's service worker. Notification content never leaves your device.

6. Children's privacy

YourTask is designed for students, including minors. Because no personal data is collected, transmitted or shared, the application does not knowingly process any personal information from children.

7. Your control

  • Export: create a .json backup at any time (Profile → Backup).
  • Delete: clearing the site's browser data removes everything permanently.
  • Uninstall: removing the installed PWA deletes the app; stored data can be cleared separately as described above.

8. Changes to this policy

Material changes will be reflected on this page with an updated effective date.
